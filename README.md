# Telegram NSFW Searcher Bot

Полноценный асинхронный Telegram-бот на базе логики `rule34_searcher.py` (Rule34, Danbooru, Pixiv).

## 🚀 Возможности

1. **Команды (через слэш `/`):**
   - `/r34 [теги] [кол-во]` — поиск постов на Rule34 (максимум до 10 постов за раз).
   - `/danbooru [теги] [кол-во]` — поиск постов на Danbooru.
   - `/pixiv [теги] [кол-во]` — поиск безопасных (SFW) артов на Pixiv.
   - `/pixivnsfw [теги] [кол-во]` — поиск R-18 артов на Pixiv.
   - `/pixivmanga [теги]` — поиск R-18 манги на Pixiv (скачивает страницы и отправляет готовым альбомом).
   - `/settings` — интерактивная панель настроек прямо в чате (сохраняется для каждой группы/чата отдельно!).
   - `/admin` — панель управления администратора (блеклист по ID, отмена запросов в чатах с пагинацией по 5 чатов на страницу). Доступна ID: `6869409295`.
   - `/start` или `/help` — список всех возможностей.

2. **Триггеры в чате (как в оригинальном модуле, без слэша):**
   - `фута` — одиночный арт с тегом `futa`.
   - `фембой` — одиночный арт с тегом `femboy`.
   - `фута + фембой` (или `фута+фембой`) — видео по тегу `futa femboy video`.
   - `порно` — случайное NSFW видео.
   - `r34 [теги] [кол-во]` — поиск по Rule34 без точки/слэша.
   - `pixiv [теги] [кол-во]` — поиск по Pixiv без слэша.
   - `pixivnsfw [теги] [кол-во]` — поиск Pixiv R-18 без слэша.
   - `pixivmanga [теги]` — манга Pixiv без слэша.

3. **Встроенные фичи:**
   - **Приветствие при добавлении в группу:** бот автоматически приветствует участников и кратко объясняет, как им пользоваться.
   - **Индивидуальные настройки для каждого чата (`/settings`):** каждая группа настраивает свои параметры (спойлеры, автоудаление, триггеры, анти-спам, дефолтный источник).
   - **Спойлер**: медиа отправляются скрытыми под спойлер.
   - **Анти-спам**: ограничение 3 запроса в 3 сек от юзера.
   - **Защита от повторов**: бот запоминает последние 50 отправленных ID по каждому тегу и не дублирует контент.
   - **Фильтр AI-контента**: исключает сгенерированные нейросетями посты при поиске на Rule34.
   - **Автоудаление**: очищает отправленные сообщения через указанное время (настраивается в `/settings`).
   - **Pixiv Keepalive**: фоновое обновление токена каждые 45 минут.

## 🛠️ Установка и запуск

1. Перейди в папку бота:
   ```bash
   cd C:\Users\malad\Desktop\plugin\nsfw_telegram_bot
   ```

2. Открой файл `.env` и укажи токен своего бота от [@BotFather](https://t.me/BotFather):
   ```env
   BOT_TOKEN=твой_токен_здесь
   ```

3. Запусти бота:
   ```bash
   python bot.py
   ```
